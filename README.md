# ✨ Aura Clínica Dental — Landing Page Premium

Landing page de demostración para una clínica dental ficticia, diseñada para transmitir profesionalismo, confianza y una experiencia de atención de alta calidad.

El proyecto fue desarrollado con **HTML, CSS y JavaScript**, utilizando **Google Antigravity como herramienta de desarrollo asistido por inteligencia artificial** para trabajar en la estructura, el diseño visual y las interacciones de la página.

## 🌐 Demo en vivo

👉 **[Ver Aura Clínica Dental](https://facundoibanez1987-eng.github.io/Aura-Clinica-Dental/)**

## 🎯 Objetivo del proyecto

Crear una landing page moderna y responsive que permita presentar los servicios de una clínica dental, comunicar su propuesta de valor y facilitar el acceso a la sección de contacto y solicitud de citas.

Este proyecto forma parte de mi portfolio de desarrollo web y demuestra cómo utilizo herramientas de inteligencia artificial para asistir en el desarrollo de interfaces web.

## 🚀 Características

- **Diseño premium:** estética visual elegante con una paleta de colores azul oscuro, blanco y dorado.
- **Diseño responsive:** adaptación de la interfaz a diferentes tamaños de pantalla.
- **Navegación interactiva:** menú con enlaces a las distintas secciones de la página.
- **Presentación de servicios:** secciones destinadas a tratamientos, filosofía y presentación de la clínica.
- **Formulario de solicitud de cita:** interfaz con validación básica de campos y una pantalla de confirmación visual.
- **Animaciones e interacciones:** efectos visuales implementados con JavaScript.
- **Recursos gráficos:** imágenes y tipografías para reforzar la identidad visual del proyecto.

## 🤖 Desarrollo asistido por inteligencia artificial

Durante el desarrollo utilicé Google Antigravity como herramienta de asistencia para:

- Explorar y desarrollar una propuesta de diseño para una clínica dental premium.
- Generar y ajustar componentes de la interfaz.
- Trabajar sobre estilos, estructura HTML e interacciones con JavaScript.
- Revisar el resultado visual y realizar ajustes mediante un flujo de trabajo iterativo.

El proceso combinó la asistencia de IA con la revisión del código y las pruebas manuales de la interfaz.

## ▶️ Cómo ejecutar el proyecto localmente

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/facundoibanez1987-eng/Aura-Clinica-Dental.git
   ```

2. Ingresar en la carpeta del proyecto:

   ```bash
   cd Aura-Clinica-Dental
   ```

3. Abrir `index.html` en un navegador o utilizar la extensión Live Server de Visual Studio Code.

No requiere instalación de dependencias para visualizar la versión estática.

## 📌 Alcance y limitaciones

Este proyecto es una demostración de frontend. El formulario incluye validación básica y una confirmación visual, pero **no envía ni almacena solicitudes en un servidor o base de datos**.

La clínica y su contenido son ficticios. El formulario no debe utilizarse para recopilar datos reales de pacientes.
